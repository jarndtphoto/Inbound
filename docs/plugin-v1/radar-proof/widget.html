About this preview

Invented aircraft and route evidence exercise Inbound's shared Nearby engine. No live aviation providers, production APIs, map tiles or external resources.

Radar and Featured use the same shared Chicago snapshot. Distances refer to the named center or airport, never your location. Coverage is available data, not every aircraft.

Symbols move locally between accepted updates. Missing track stays neutral; stale positions stop; accepted altitude is unchanged. A new fix replaces the display trajectory.

Inline fallback. ChatGPT host behavior is awaiting manual verification.

Nearby refresh calls: 0. This UI sends no chat messages or model requests.
